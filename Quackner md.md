# Sleek QR & Barcode Studio

A modern, fully responsive web application built for generating and scanning QR codes (Normal & WiFi) and Barcodes (CODE128). Features a dark-mode glassmorphic interface, history tracking, screenshot decoding, and local export capabilities.

## Project Structure
- `index.html`: Main HTML entry point and external CDN dependencies.
- `css/style.css`: Custom design tokens, layout styles, and animations.
- `js/app.js`: QR/Barcode generator logic, camera scanner, screenshot decoder, and local storage history.
- `assets/`: Directory for static images, logos, or icons.

## Features
- **Generator Mode**: Create customized Normal QR codes, WiFi configuration QR codes, and Barcodes with custom colors.
- **Live Scanner**: Real-time camera QR and barcode reader.
- **Screenshot Scanner**: Upload and decode QR codes from saved image files.
- **History Log**: Local storage persistence to manage previously generated and scanned codes.
